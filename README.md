# 庭とジム

「ねむりの庭」と「マッチョクラブ」の入口です。iPhone のホーム画面にはこの入口だけを置き、ここから2つのアプリを開きます。

同じホーム画面のアイコンの中で行き来するので、2つのアプリの保存場所（localStorage）が共通になり、ねむりの庭の今朝の睡眠をマッチョクラブの試合のコンディションに使えます（iPhone ではホーム画面のアイコンごとに保存場所が分かれるため）。

- ねむりの庭：/nemuri-garden/
- マッチョクラブ：/kintore/

## 手元で動かす（このフォルダの一つ上から）
```
python app-hub/tools/serve-all.py 8125
```
公開先と同じ並び（/ が入口、/nemuri-garden/ と /kintore/ がそれぞれのアプリ）で配ります。アイコンは http://localhost:8125/tools/make-icons.html で作り直せます。
